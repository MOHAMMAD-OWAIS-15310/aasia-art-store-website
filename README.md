# Aasia Art Store

## Overview

Aasia Art Store is a full-stack e-commerce web application developed for my SISTER'S art business to showcase and sell original paintings online. The project was built to solve a real user need by providing customers with a secure and user-friendly platform to explore artwork, create accounts, manage their cart, and purchase paintings online.

Developing this project gave me practical experience in designing, building, and deploying a real-world full-stack application while working with authentication, database management, cloud storage, and production deployment.

**Live Demo:**
https://aasia-art-store.onrender.com/listings

---

## Features

* User registration and secure authentication
* Email-based OTP verification
* Role-based authorization using Passport.js
* Browse artwork with detailed product pages
* Add paintings to cart and save them 
* CRUD operations
* Image upload and management using Cloudinary
* Session management with MongoDB
* Responsive user interface built with Bootstrap
* Flash messages for user feedback
* Deployed on Render for public access
* Payment integration (currently under development)
